# SLV Dental Clinic & Implant Centre - 100% Static Website

A high-performance, **completely serverless static one-page website** for **SLV Dental Clinic & Implant Centre** in Haralur, Bangalore.

---

## ⚡ Zero-Server / Pure Static Execution

This website requires **NO web server, NO backend, and NO database** to run:

1. **Direct Double-Click to Open:**
   - Open [`dist/index.html`](dist/index.html) directly in any web browser (Chrome, Safari, Firefox, Edge).
   - All HTML, CSS, JavaScript logic, Lucide icons, and clinic photos are **100% self-contained** in the static file.

2. **Deploy Anywhere for Free:**
   - Works immediately on **GitHub Pages**, **Netlify**, **Cloudflare Pages**, **Vercel**, **AWS S3 / Firebase Hosting**, or any standard web host with zero configuration.

## 🛠️ Modifying Clinic Data or Email

To change the phone number, email address, or add new services, edit [`src/data/clinicData.js`](src/data/clinicData.js) and run:

```bash
npm run build
```

This will re-compile the single-file standalone bundle in `dist/index.html` in under a second.
